## What has actually run

The [v0.2 catalog](CATALOG_STUDY.md) used eight generic Ridge/ExtraTrees recipes, official CorNet and official DataFusionPPI **DR**: 79,104 applicable records, 79,083 successful fits and 21 terminal failures. These are fixed benchmark recipes, not reproduced source-paper tables. A translated DGP does not establish an estimator's availability. The canonical 31 presets derive from six paper sources plus structural comparisons; KPS, Elastic, power likelihood and CVCI estimators remain absent from the public package. Integrative R and Causal-ICM are optional fixed recipes, with native execution checks separate from v0.2.

The [subsequent GP pilot](../results/gp_source_pilot/SCIENTIFIC_RESULT.md) compares full OBS+RCT, genuinely RCT-only and OBS-conditioned trial starting predictions at fixed rho=0.5: 576 successful fits, zero failures or missing records, six conditions and 32 paired seed blocks. OBS addition reduced mean MSE at discrepancy levels 0/1 but caused negative transfer at level 2 at both trial budgets. Its pointwise intervals are unadjusted descriptive Monte Carlo summaries. The prior-shrunken OBS starting prediction is not an optimal OBS-only estimator.

The PPI adapter accepts `learner="R"`, but the catalog did not run that option. See [verification](VERIFICATION.md) and the [frozen results](../results/catalog_study/SCIENTIFIC_RESULT.md).

The separate [causal-forest admission](../results/causal_forest_admission/README.md) verifies one official `grf` RCT-only default recipe through six native fits, direct/fresh-process agreement, independent weighted-regression prediction arithmetic and two cost fixtures. The subsequent [native/default panel](../results/native_panel/SCIENTIFIC_RESULT.md) compares that recipe with the declared eleven-recipe set. R-learner and Bayesian causal forest remain planned.

## Assumptions are part of a method's row

Each machine record separates data and propensity requirements, support, transport and modeling assumptions. A method may be runnable in an assumption-violation scenario; its error there is a stress-test result. Conversely, missing dependencies or code leave a candidate **pending**, not mathematically unsupported. An actual API restriction, such as the locked PPI adapter's constant trial propensity requirement, is an implementation incompatibility and must be labeled separately from the paper's scope.

Targets must record the conditioning variables and the population. C08, the hidden effect-modifying participation scenario, violates trial-to-target conditional-effect transport; this does not imply that all available data fail to identify its target. M10, a source-effect-shift scenario, and the CorNet/CVCI translations instead have OBS-to-target effect shift while trial and target effects agree; see the [scenario classification](V03_SCENARIOS.md). Validation on trial outcomes targets the trial distribution unless a valid transport rule is declared. With variable trial propensity, ordinary R-loss weights CATE error by `e(X)*(1-e(X))`; it is not unweighted target MSE. [Nie and Wager, §2](https://arxiv.org/html/1712.04912v4).

## Source and execution status

The inventory distinguishes paper verification, official code inspection, public adapter existence, benchmark execution and source-paper reproduction. Read-only checks inspected primary papers, official repository metadata/README/API documentation and declared licenses. Repository revisions were queried at the cutoff; they are candidate references, not new executable dependency locks. Existing executable pins remain in [sources.lock.toml](../sources.lock.toml).

PPI paper **v2 was posted on 2026-10-23**. The official repository's cutoff revision remains `04c7f3447b02fa09f875e68e8c47100a7207d546`, committed on 2026-10-07, which is the executed v0.2 pin. A paper revision is not evidence of a code change or of paper/code equivalence. Reviewing that equivalence remains pending. [Paper history](https://arxiv.org/abs/2610.12332v2), [official code](https://github.com/CausalDataScience/DataFusionPPI/tree/04c7f3447b02fa09f875e68e8c47100a7207d546).

Official code was verified for KPS, integrative R, Elastic, CVCI, Causal-ICM, IntegrativeHTEcf and partial identification, as well as the existing adapters and proposed RCT controls. Several have no root license file; package metadata sometimes supplies a license instead. The record states exactly what was found. The old IntegrativeHTEcf README still says its paper is forthcoming and uses an old installation account, so correspondence to the final 2025 paper needs a method/API review before admission. Official implementation discovery remains pending for Cheng–Cai, Rosenman and the adaptive candidates; no exhaustive absence claim is made.

The linear/quadratic Integrative R and fixed-rho Causal-ICM recipes have [native execution and bounded cost checks](../results/native_adapter_admission/README.md). The default RCT-only causal forest has its [separate native admission](../results/causal_forest_admission/README.md). The fixed GP and its two source controls also have the separately frozen [576-fit development pilot](../results/gp_source_pilot/README.md). These are checked benchmark recipes, not reproduced source-paper tables. Other proposed methods and the broader campaign remain pending native-target mapping, execution arrangements, immutable environment records, independent scientific checks and bounded server costs. Admission and pilot fixtures do not fix the later campaign grid.
